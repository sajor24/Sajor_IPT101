# 💕 For My Love Mami - Love Letter App

A romantic web application created with love, featuring:

## Features:
- 🎵 **Background Music**: "Panalangin" by APO Hiking Society
- 📸 **Photo Gallery**: Beautiful memories together
- 💌 **Love Letters**: Heartfelt messages
- ⏰ **Anniversary Countdown**: Days together counter
- 💕 **Mobile Responsive**: Works perfectly on phones

## How to Use:
1. Click "🎵 Play Music" to start the romantic background music
2. Explore "📸 Your Picture" to see your beautiful photos
3. Read "💌 Love Letters" for sweet messages
4. Check "⏰ Countdown" for anniversary tracking
